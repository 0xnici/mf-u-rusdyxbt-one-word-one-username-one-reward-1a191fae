One word, one username, one reward. A deterministic Python entrypoint writes a single, memorable make.fun handle to `/output/entry.txt` — no network, no dependencies, same bytes every run.

## Run it

```sh
mkdir -p /tmp/makefun-output
MAKEFUN_OUTPUT_DIR=/tmp/makefun-output python3 -P -s main.py
cat /tmp/makefun-output/entry.txt
```

The grader supplies its own writable `MAKEFUN_OUTPUT_DIR` (normally `/output`) and reads the word from `entry.txt` there.
